Research Papers Relevant to Face Recognition Attendance Project

Prepared for college presentation and academic explanation

1. RetinaFace: Single-stage Dense Face Localisation in the Wild

Why it matches the project

https://arxiv.org/abs/1905.00641
  • This paper is highly relevant because the first crucial step in any face recognition system is accurate face detection.
  • It focuses on detecting faces under difficult real-world conditions such as varying pose, scale, illumination, blur, and partial occlusion.
  • In our attendance system, the camera captures live frames and the system must detect the face correctly before extracting identity features.

Comparison with our project: RetinaFace is focused on detection accuracy, while our project extends this detection stage into a complete real-time attendance system that adds recognition, liveness checks, quality analysis, and database logging.

2. FaceNet: A Unified Embedding for Face Recognition and Clustering

Why it matches the project

https://arxiv.org/abs/1503.03832
  • FaceNet is one of the foundational papers in face recognition.
  • It shows how face images can be transformed into compact embedding vectors, making recognition and comparison easier and more accurate.
  • This is directly aligned with our project, since the system recognizes students by comparing feature embeddings, not just raw images.

Presentation angle: “Our project uses deep feature representation for identity matching, following the core idea introduced by FaceNet.”

3. ArcFace: Additive Angular Margin Loss for Deep Face Recognition

Why it matches the project

https://arxiv.org/abs/1801.07698
  • ArcFace is one of the most widely used face recognition losses in modern biometric systems.
  • It improves feature separation so different faces are farther apart and similar faces are closer together in embedding space.
  • This aligns with our recognition model because identity matching depends on robust feature representation.

Presentation angle: “ArcFace improves the discrimination power of the embedding space, making the attendance system more accurate and reliable.”

4. You Only Look Once: Unified, Real-Time Object Detection

Why it matches the project

https://arxiv.org/abs/1506.02640
  • YOLO is a classic real-time object detection model and remains highly relevant to computer vision projects.
  • It is important for systems that need to process live video streams with limited latency.
  • This is relevant to our attendance system because the system must detect and process people quickly in real time.

Presentation angle: “YOLO demonstrates the importance of real-time detection, which is essential for classroom attendance tracking.”

5. Billion-scale similarity search with GPUs

Why it matches the project

https://arxiv.org/abs/1702.08734
  • This paper is directly connected to FAISS, which is used for fast similarity search in large embedding databases.
  • After generating face embeddings, the system needs to find the nearest match quickly among many enrolled student faces.
  • FAISS enables efficient matching in high-dimensional vector space, which is central to attendance verification.

Presentation angle: “Our project uses vector search to compare live faces against a stored database of student embeddings efficiently and at scale.”

Professor-friendly comparison summary

RetinaFace provides the face detection foundation. It ensures the system locates the face correctly in real-world conditions.

FaceNet and ArcFace provide the recognition foundation. They convert faces into robust high-quality embeddings and improve identity discrimination.

YOLO represents the real-time detection philosophy that supports live monitoring and quick frame-to-frame processing.

FAISS supports efficient matching against large student datasets.

Our project combines all of these ideas into a single practical system: camera input → face detection → face quality/liveness validation → embedding generation → similarity search → attendance logging.

Best paper to emphasize in the presentation

If you want the strongest paper to explain in detail to your professor, use RetinaFace as the third key paper. It aligns most directly with your project because real-time attendance recognition depends critically on reliable face detection as the first step in the pipeline.

Final Summary

Our project follows a standard deep face-recognition pipeline: detect the face, verify quality, generate a deep embedding, compare it with stored identities, and mark attendance automatically. This approach is strongly supported by research in face detection (RetinaFace), embedding-based recognition (FaceNet), discriminative learning (ArcFace), real-time vision (YOLO), and vector search (FAISS).
