# Asset Credits & Visual Attribution

All cinematic visual assets, diagrams, and animations included in this repository are custom-engineered for the **Face Recognition Attendance System 2.0** showcase.

## Visual Design & Architecture

- **Visual Architecture & Storyboards**: Developed natively for the Face Recognition AI 2.0 platform.
- **Cinematic Animations**: Programmatically synthesized vector animations rendered using PIL/Pillow and NumPy under dark-mode obsidian themes (`#080C16`, `#00F0FF`, `#3B82F6`, `#10B981`).
- **Typography**: System UI font stack (Segoe UI, Arial, Consolas) under standard Microsoft OEM licensing.
- **Diagrams**: Native GitHub Flavored Markdown and Mermaid.js diagrams.

## AI Models & Research Foundations

1. **YOLOv8-Face**: Ultralytics Real-Time Object Detection Framework (AGPL-3.0 / Enterprise).
2. **ArcFace (Additive Angular Margin Loss)**: InsightFace Deep Face Analysis Project (MIT / Apache-2.0).
3. **MiniFASNetV2**: Silent-Face-Anti-Spoofing deep anti-spoofing neural network architecture (Apache-2.0).
4. **FAISS (Facebook AI Similarity Search)**: Meta Open Source Vector Database Library (MIT License).
5. **FastAPI**: Sebastián Ramírez / Tiangolo (MIT License).
6. **Streamlit**: Snowflake Inc. (Apache-2.0 License).
